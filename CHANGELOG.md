# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-05-21

### Added
- Initial release of skillsync
- Central skill repository at `~/.skillsync/skills`
- CLI commands: init, doctor, list, validate, sync, import, target
- Adapter support for Claude Code and Cursor
- Copy and symlink sync modes
- Hash-based idempotency tracking
- Dry-run mode for safe preview
- JSON output for all commands
- Comprehensive test suite with 28 tests
- GitHub Actions CI workflow
- MIT License
